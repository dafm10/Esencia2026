# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Usa **Security → Report a vulnerability** en este repositorio
(reporte privado) o escribe al responsable indicado en `CODEOWNERS`.

Incluye: descripción, pasos para reproducir, impacto y versión/commit afectado.
Se responde en un plazo razonable y se coordina la divulgación tras publicar el arreglo.

## Alcance

Aplicación web (React/Vite), funciones Edge (Supabase) y configuración del repositorio.
Fuera de alcance: ataques de ingeniería social o denegación de servicio volumétrica.
